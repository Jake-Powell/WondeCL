# Extract class lists for schools using class or registration group structures

This function creates a detailed class list for schools where teaching
groups are organised by \*classes\* or \*registration groups\* rather
than by subjects. It compiles student, class, and teacher information
for the specified year code(s) across all schools included in the
provided Wonde dataset list.

## Usage

``` r
extract_class_list_classes_groups(
  WondeData,
  schools,
  yearCodes,
  verbose = TRUE
)
```

## Arguments

- WondeData:

  A named list of school datasets, typically generated by Wonde data
  retrieval functions (e.g.,
  [`get_primary_school_student_data`](https://Jake-Powell.github.io/WondeCL/reference/get_primary_school_student_data.md)).
  Each element represents one school's full dataset.

- schools:

  A data frame containing metadata for the schools, including at least
  the columns:

  id

  :   Wonde school ID (matches names of `WondeData`)

  urn

  :   Unique Reference Number

  classes

  :   Indicator or description of whether class data are available

  registration_groups

  :   Indicator or description of whether registration group data are
      available

- yearCodes:

  Character vector of year codes identifying the students to include
  (e.g. `c("YR", "R")` for Reception, `"Y1"` for Year 1, etc.).

- verbose:

  Logical (default = TRUE). Whether to print progress messages and
  warnings for missing or inconsistent data.

## Value

A data frame containing class list information for the selected year
code(s) across all schools, with columns:

- SchoolId:

  Wonde school ID

- SchoolName:

  School name

- EstablishmentNumber:

  Establishment number from Wonde

- URN:

  Unique Reference Number

- UPN:

  Unique pupil number (if available)

- StudentId:

  Wonde student ID

- StudentFirstName:

  Student forename

- StudentLastName:

  Student surname

- DoB:

  Student date of birth (YYYY-MM-DD)

- ClassId:

  Class or registration group ID

- ClassName:

  Class or group name/code

- TeacherId:

  Teacher’s Wonde ID

- TeacherForeName:

  Teacher’s forename

- TeacherSurName:

  Teacher’s surname

- TeacherName:

  Combined teacher name

## Details

The function supports two data structures:

- **Class structure:** where students are linked via `students_classes`.

- **Registration group structure:** where students are linked via
  `students_group` with `groups.data__type == "REGISTRATION"`.

The function first attempts to build the class list using the
`students_classes` dataset. If no valid class data are available for a
school, it falls back to using registration group data from
`students_group`. Warnings are issued for schools or students that
cannot be matched across datasets.

## See also

[`extract_class_list`](https://Jake-Powell.github.io/WondeCL/reference/extract_class_list.md)
for the version that uses subject-based structures (typically for
secondary schools).
